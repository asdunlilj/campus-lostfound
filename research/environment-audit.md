# 本机环境体检报告（2026-11-08 实测）

> 隐私说明：本文件为公开发布版本，具体 IP 地址、网关、SSID 与设备型号已脱敏替换为等价示例值；网络类型与可达性结论不受影响。
> 用途：方案评审的事实依据。命令均为只读检查，未改动系统。

## 1. 硬件与系统
| 项 | 实测值 | 对"本机做服务器"的影响 |
|---|---|---|
| 型号 | LENOVO 笔记本（型号略去） | 笔记本 7x24 运行需处理睡眠/合盖/电池；不适合作为生产级单点 |
| CPU | AMD Ryzen 5 5500U，6C/12T | 足够支撑本项目的内网并发（几十人） |
| 内存 | 13.8 GB 物理，**空闲仅 3.0 GB** | MySQL + C++ 服务 + 浏览器 + 开发工具会吃紧，需控制常驻服务 |
| 磁盘 | C: 50.0 GB 空闲 / D: 90.3 GB 空闲 | 纯文本数据没问题；**照片长期存储需规划**（10 万张 2MB 约 200GB） |
| 系统 | Windows 11 家庭版 Insider Preview 26220 | 家庭版无 Hyper-V/组策略；Insider 通道存在自动更新与不稳定风险 |
| 电源 | 平衡方案；支持 S3 睡眠；休眠未启用 | **必须改为"从不睡眠"、合盖不睡眠、禁用无线网卡节能**，否则服务随时断 |
| 电池 | 95% | 可短时充当 UPS，但电池老化后不可靠 |

## 2. 网络（关键风险）
| 项 | 实测值 | 影响 |
|---|---|---|
| 联网方式 | **仅 WLAN**（Realtek 8822CE，802.11ac 5GHz，585 Mbps） | 无线做服务器稳定性/延迟不如有线；无有线网口可用（可买 USB 千兆网卡） |
| SSID / 认证 | 校园 Wi-Fi，Open / Cipher None（无 Wi-Fi 密码，疑似校园 Portal 认证网） | 同网设备能否互访未知；**大概率存在客户端隔离 / AP 隔离** |
| IP / 掩码 | 192.168.1.100/**24**，网关 192.168.1.1 | 单一广播域的校园网，DHCP 租约会变；跨网段访问取决于校园网策略 |
| 防火墙配置 | 域/专用/公用 三个配置文件**全部启用**，当前网络被识别为 **Public** | Public 配置默认**拒绝入站**；需为服务端口显式添加入站规则 |
| 默认路由 | 192.168.1.1 via WLAN | 仅校园网内可达，手机切 4G 就访问不到 |

**结论：必须先做"手机 ↔ 本机"可达性实测，再谈开发。** 若校园网启用客户端隔离，则本机服务器方案在校园 Wi-Fi 上直接不成立，需改为自建路由器/热点、或部署到有公网入口的服务器、或用内网穿透。

## 4. 端口占用
80 / 443 / 3000 / 3306 / 5173 / 8080 / 8081 / 8443 **均无监听**（MySQL 未启动），端口选择自由；但校园网可能在上层策略上封禁 80/443 入站（需实测）。

## 5. 对方案的直接影响（摘要）
1. 本机是**笔记本 + 无线 + 校园网 + Public 防火墙**，是"能跑通演示"和"能稳定提供服务"之间差距最大的组合，必须在方案里明确降级与兜底。
2. 手机端要拍照上传/装 PWA/收通知 → 必须 HTTPS；而本机没有域名，**证书方案是必答题而不是可选项**。
3. 开发环境从零装：VS Build Tools(MSVC) + CMake + vcpkg + Node/pnpm + 启动 MySQL，建议写成脚本一次性完成并验证。
